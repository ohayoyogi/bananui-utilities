## アプリ

### メモ帳

- 一覧、新規作成、複数行編集、保存、再読込み、削除確認。
- 日本語の入力・かな漢字変換はBananuiの共通IMEと既存の`bInputWidget`を使う。アプリ専用の変換エンジンは追加しない。
- メモはUTF-8の`<UUID>.txt`。先頭の空でない行を一覧の見出しにする。保存上限は1件16KiB。日本語は概ね数千文字。
- 編集から500ms後に下書きを自動保存し、次の起動で復元する。正式な保存は左ソフトキー。保存できない場合はエラーを表示し、通常の終了操作では編集内容を残して終了を止める。
- 保存先の内容が別の操作で変更されていれば上書きを止め、別メモとして保存する選択肢を出す。時刻の細かさだけに依存せず、内容のSHA-256とファイルのetagを使って確認する。
- 削除したメモはアプリの`.trash`フォルダへ移す。復元用の画面は初期版にない。中のUTF-8ファイルは手動で読める。
- 同じユーザーの同じsession D-Busでは、一つのアプリとして起動する。

| 画面 | キー | 操作 |
|---|---|---|
| 一覧 | 上下／決定 | 選択／開く |
| 一覧 | 左ソフト（F1） | 新規作成 |
| 一覧 | 右ソフト（F2） | 削除の確認 |
| 一覧 | クリア／Escape | 終了 |
| 編集 | 左ソフト（F1） | 保存 |
| 編集 | 右ソフト（F2） | 一覧へ。未保存なら保存／破棄／編集継続を選ぶ |
| 編集 | 決定 | 改行。IMEの変換中は先に変換を確定する |
| 編集 | 方向／クリア | カーソル移動／一文字消去。変換中はIMEの操作を優先 |

数字キーの文字割当て、`#`の入力モード切替、変換キーはシェルの共通IME設定に従う。既定で右ソフトが後変換に割り当てられている場合、変換中はまず決定で確定してから一覧操作を行う。終話キーはシェルの共通動作が優先される。

保存先は通常`$XDG_DATA_HOME/bananui-utils/notes/`、未設定なら`~/.local/share/bananui-utils/notes/`。メモのファイルは0600、新規ディレクトリは0700で作る。`--data-dir PATH`でテスト用の保存先を指定できる。下書きは同じフォルダの`.draft.ini`。壊れた下書きは別名で退避し、黙って上書きしない。

下書きは最後の入力から500msの間隔で保存する。強制終了・電源断・保存先の障害時に、直前の全キー入力を保証するものではない。未読・通話・端末のサスペンド等の制御は行わない。

### 電卓

| キー | 操作 |
|---|---|
| 数字 | 数値入力（12桁まで） |
| 上／下／左／右 | ＋／−／×／÷ |
| 決定 | 計算。続けて押すと直前の演算を繰り返す |
| ＊／＃ | 小数点／符号反転 |
| クリア | 入力中の一文字を消去 |
| 左ソフト（F1） | 全消去 |
| 右ソフト（F2） | 終了 |

入力した順に計算する方式。`2＋3×4＝`は20になる。表示は最大12桁相当、計算は浮動小数点で行う。ゼロ除算や桁あふれを説明し、数字の入力でやり直せる。PC用には`+ - * / . =`も受け付ける。履歴・メモリー演算・関数計算は初期版の範囲外。

## 構成

- `src/note-store.*`：GLib/GIOだけに依存する保存・一覧・下書きの処理。
- `src/calculator.*`：GLibと標準数学ライブラリだけに依存する計算処理。
- `src/notes.c`、`src/calculator-app.c`、`src/ui.*`：Bananui／Cairo／Pangoの表示とキー操作。
- `.desktop`ファイル：`org.bananui.Notes.desktop`、`org.bananui.Calculator.desktop`。既存のメニューに通常のアプリとして登録できる。

アプリ独自のシェル専用D-Bus APIやKYF31のデバイスノードには依存しない。表示はlibbananui、入力はWaylandのtext-input-v3と対応IMEが利用できる環境を前提とする。別のUIへ移す場合も、保存・計算のコアは分けて流用できる。

## 共通入力部品の修正

検証に使用したlibbananuiには`src/input.c`と`src/input_method.c`の修正を含む。空欄をIMEへ報告する際の範囲外参照、UTF-8削除時に余計な領域まで読む処理、別文書を設定した後にカーソルがUTF-8の途中へ残る問題を修正した。併せて文字列の解放を整理。公開API・ABIは変更していない。

このアプリの確認には修正版を使用した。古いライブラリをそのまま使う前提にはしない。依存版と修正の適用方法は[DEPENDENCIES.md](DEPENDENCIES.md)を参照。ライブラリ本体はこのリポジトリに含めず、当面は再現用の差分だけを`patches/`に保持する。

## ホストでビルド・確認

Ubuntu 24.04／WSL2で確認した。開発依存はMeson、Ninja、Cコンパイラ、GLib/GIO、Pango/Cairo、librsvg、Wayland/protocols、xkbcommon。日本語表示にはNoto CJK等のフォントが必要。画面試験はphoc、wtype、grim、D-Busを使う。

必要な修正を適用したlibbananuiを先にビルド・インストールし、このリポジトリのルートで実行する。

```sh
meson setup build --prefix="$HOME/.local"
meson compile -C build
meson test -C build --print-errorlogs
meson install -C build
```

libbananuiを専用prefixへ配置した場合は、その`lib/pkgconfig`（環境によっては`lib/<triplet>/pkgconfig`）を`PKG_CONFIG_PATH`へ追加し、実行時の共有ライブラリ検索パスも設定する。Mesonのインストール先も必要に応じて同じprefixにする。

保存・計算の7ケースは`meson test`で実行する。画面試験にはWaylandセッションが必要。`build/test-input-widget`は稼働中のコンポジタと対応する入力環境に接続する回帰試験で、自動テストには登録していない。

保存・計算だけをUIなしでメモリ検査する場合（Cコンパイラ、pkg-config、GLib/GIOの開発ファイルが必要）：

```sh
sh scripts/check-core-asan.sh
```

2026-11-09の画面試験は独立したheadless phocセッションと合成したメモデータを使った。日本語変換、保存・再起動・下書き復元、未保存の破棄確認、外部変更時の別メモ保存、ゴミ箱、電卓のキー操作を確認した。入力部品の検証では空欄、511バイト＋終端のバッファ境界、31行の移動・スクロール、日本語のカーソルを扱った。シェルを含む統合試験の手順・画面記録はKYF31側の構成記録で管理する。

ビルドしたホスト用バイナリはx86_64。ARM端末向けには対象環境に合わせたビルドが必要。
